Operating System

Directories
- `kernel/`: Core kernel and system calls
- `drivers/`: Device drivers grouped by domain
- `hal/`: Hardware abstraction layer and contracts
- `fs/`: Filesystem implementations
- `net/`: Networking stack
- `audio/`: Audio stack
- `graphics/`: Display, compositor, input
- `lib/`: Userland and kernel shared libraries
- `userland/`: Shells, services, desk UI
- `config/`: System configuration defaults
