Contributing Guide

Thank you for your interest in contributing!

How to Contribute
- Open an issue to discuss significant changes before starting work.
- For code changes, fork and open a PR against `main`.
- Follow code style and structure described in `docs/development/`.

Areas of Contribution
- Documentation (overview, architecture, build, APIs)
- Bootloader, kernel, drivers, HAL, userland
- Tooling, build system, CI

Development Workflow
- Small PRs are preferred
- Include tests where applicable
- Update docs when behavior or interfaces change
