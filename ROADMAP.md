Roadmap

Phase 0 – Project Inception
- Project governance, contribution docs, repo structure
- Hardware research and public docs policy
- Architecture sketches and ADR templates

Phase 1 – Boot to Kernel Shell (MVP)
- Bootloader bring-up on x86-64 reference hardware
- Minimal kernel: paging, interrupts, scheduling, basic syscalls
- Console I/O: framebuffer and keyboard

Phase 2 – Drivers and HAL
- Input (HID), storage, network, audio skeletons
- Filesystem and configuration layout
- IPC and service model

Phase 3 – Userland Foundations
- Process model, runtime libraries
- CLI tools and service management
- Graphics and UI compositor groundwork

Phase 4 – Lighting Desk UX
- Patch/Show data model and persistence
- Channel control pipeline and timing
- UI for playback, groups, palettes, cues

Ongoing
- Documentation, testing, CI, community onboarding
