IonXE Backend Service

Run

```
cargo run -p ionxe-backend
```

API

- GET /health
- GET /api/v1/patch
- PUT /api/v1/patch
- POST /api/v1/patch/universes
- POST /api/v1/patch/fixtures
- POST /api/v1/patch/channel_map
- GET /api/v1/routing
- PUT /api/v1/routing

State persists to `build/state/patch.json` and `build/state/routing.json`.
